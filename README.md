# HOUSE OF AI® — Client Factory

White-label implementation starter kit for reusable client intake, payment fulfillment, email, onboarding and approval workflows.

**Status:** SOP and configuration templates, not yet a live provisioning platform.

**PUBLIC REPOSITORY NOTICE:** Do not commit credentials, customer information, private logo assets, or confidential client materials. Remember to change visibility to **Private** once setup is complete.

## Reusable workflow

Create a client workspace → configure branding and offer → configure Stripe and email separately → collect guided onboarding snapshot → verify purchase and entitlement → send welcome and boarding pass → review and approve launch.

See `AGENTS.md`, `docs/launch-checklist.md` and `config/client.template.json`.
